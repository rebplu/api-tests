API Gebietsstammdaten Kanton Zürich

Diese API ermöglicht den einfachen Zugriff auf aktuelle und qualitätsgesicherte Stammdaten der Gemeinden, Bezirke und Raumplanungsregionen des Kantons Zürich.

GET /api/gemeinden Alle Gemeinden abrufen
GET /api/gemeinden/{gemeinde_code} Einzelne Gemeinde mit dem Gemeindecode (Bfsnr) abrufen
GET /api/gemeinden/gemeindename Suche nach Gemeinden anhand des Gemeindenamens
GET /api/bezirke Alle Bezirke abrufen
GET /api/raumplanungsregionen Alle Raumplanungsregionen abrufen
GET /api/gemeindemutationen Gemeindemutationen seit 1990 abrufen
...

Geplante Weiterentwicklungen

Erweiterung der Daten

Die Gebietsstammdaten werden schrittweise um zusätzliche Attribute und weitere Gebietstypen (wie beispielsweise Schulgemeinden) erweitert, wodurch sich auch der Funktionsumfang der API vergrössert.

Abfragen & Endpunkte

Die API wird basierend auf Rückmeldungen und dem Bedarf der Community kontinuierlich um neue Abfragemöglichkeiten erweitert.

Reconcile Service für OpenRefine

Der Reconcile-Service für OpenRefine ermöglicht eine komfortable Zuordnung sowie Bereinigung eigener Daten ohne Programmierkenntnisse und wird von uns stetig optimiert.
